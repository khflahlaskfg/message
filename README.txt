رسالة صغيرة للين — النسخة الأردنية وتعليمات النشر

1) افتح index.html في متصفحك لتجربة الموقع محليًا.
2) قبل النشر، افتح index.html وابحث عن:
   const ANAS_WHATSAPP_NUMBER = "";
   أضف رقم واتسابك بصيغة دولية من دون علامة + أو مسافات أو شرطات.
   مثال توضيحي فقط: 9627XXXXXXXX (استبدله برقمك الحقيقي).
3) ارفع index.html إلى المجلد الرئيسي في GitHub repository.
4) من Settings > Pages اختر Deploy from a branch ثم main و /(root)، ثم Save.
5) افتح رابط GitHub Pages الذي يظهر بعد النشر.

كيف يصل اختيار لين إليك؟
بعد أن تختار لين أحد الأزرار، يظهر لها زر إضافي اختياري: «خلّي أنس يعرف اختيارك».
إذا أضفت رقم واتسابك في السطر المذكور أعلاه، يفتح واتساب برسالة جاهزة، ولن تُرسل تلقائيًا؛ لين هي التي تختار الإرسال.
إذا تركت الرقم فارغًا، يحاول الموقع فتح قائمة المشاركة على جهازها، أو نسخ الرسالة لتُرسلها يدويًا.
الموقع لا يرسل اختيارها بصمت ولا يخزّن بياناتها.
